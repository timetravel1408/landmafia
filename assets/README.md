# Assets

There are no binary art or audio files in this project — by design, everything is original and
generated in code:

- `client/src/sprites.ts` — mounted knight (2 animation frames, rotated to 8 facings), fort tiers
  (camp → fort → castle → citadel) in every heraldic colour, towers, crown, coin, broken sword.
- `client/src/style.css` — carved-wood panels, parchment, wax-seal buttons (pure CSS gradients).
- `client/src/audio.ts` — synthesized WebAudio sound effects (muted by default).

If you add hand-made or third-party assets later, put them here and record their licence
(original or CC0 only — no material from existing commercial games).
